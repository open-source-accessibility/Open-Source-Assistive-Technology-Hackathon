# Open Source Assistive Technology Hackathon

[Register for the 2027 Open Source Assistive Technology Hackathon.](https://www.eventbrite.com/e/open-source-assistive-technology-hackathon-2027-tickets-2004909405001)

GitHub is committed to [improving the accessibility of open source software](https://github.blog/open-source/social-impact/our-pledge-to-help-improve-the-accessibility-of-open-source-software-at-scale/#reference1) and empowering people with disabilities to actively contribute. In collaboration with many [partners](), we're hosting an “Open Source Assistive Technology Hackathon” focused on empowering participants to build skills and make real contributions to the assistive technology tools people rely on every day.

The hackathon will occur the **weekend before the CSUN conference** at a location that is a 15 minute drive from the CSUN conference venue. We invite you to come to Anaheim for the hackathon and stay for the conference.

**Ready to contribute?** We will have a list of featured open source AT projects to choose from! Featured project list is coming soon.

**We’re seeking projects to feature!** If you maintain (or contribute to) an AT project and would like your project to be part of the hackathon - whether it needs docs improvements, triage support, testing, or small starter issues - please fill out the project submission form.

## Event Details

- **Cost:** Free!
- **Dates:** March 6 – 7, 2027
- **Location:** Braille Institute Anaheim (527 North Dale Avenue Anaheim, CA 92801)
- **Food:** Expect light breakfast options each morning and catered lunch on both days. More details will be found in the agenda closer to the event.
- **Services provided:** ASL interpretation and CART captioning.
- Please note that you must be **18+** to attend this event.

## Who Should Attend

- People with lived experience who want to innovate on assistive technology
- Developers with disabilities
- Assistive Technology specialists
- Developers with a desire to help improve and customize assistive technologies
- Professionals working in the field of special education, rehabilitation engineering, biomedical engineering, and other fields that can benefit from free open source assistive technology
- Open source AT maintainers

We’d love your participation in this event. [Sign up for the event using this form](https://www.eventbrite.com/e/open-source-assistive-technology-hackathon-2027-tickets-2004909405001).

**If using NVDA**, you may encounter an issue when registering. Please follow these steps: 
1. Click reserve a spot.
2. That opens a dialog, but NVDA cannot read it.
3. Workaround: Relaunch NVDA so you can read the dialog.
